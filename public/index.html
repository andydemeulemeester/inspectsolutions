Projecten

Kies het project waaraan je werkt. Elk project heeft een eigen Google Sheet, een eigen fotomap en een eigen nummering.

Eerste start. Vul hieronder de verbinding met de Google Sheet in. Doe dit met internet aan. Daarna werkt de app ook zonder verbinding.

Verbinding

Het webadres van het Apps Script staat al ingevuld. Vul enkel de geheime sleutel in. Ze worden enkel op dit toestel bewaard.

Codelijst

Eén item per regel, in de vorm CODE | omschrijving. Een regel zonder code krijgt automatisch een code. Bestaande punten behouden hun oorspronkelijke code en tekst.

Gegevens

Stuurt alle projecten, punten en foto’s opnieuw naar de Sheet, bijvoorbeeld na een nieuw script of als een Sheet verwijderd is. Bestaande rijen worden bijgewerkt en foto’s vervangen, er komen geen dubbelen.

Wist alle punten van alle projecten op dit toestel en laat de nummering opnieuw bij 1 beginnen. De projecten blijven bestaan.
